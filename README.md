## Why Spark

[Shine](https://github.com/asticore/shine) does styling with **no JavaScript**: buttons, cards, modals, carousels, tooltips and colors.
Some effects can't be done in CSS alone. Canvas particles, pointer tracking, scroll math, timers and focus handling all need code.
**Spark is that code.** It works the same way Shine does:

| | Shine | Spark |
|---|---|---|
| Turn it on | `class="btn"` | `class="spark-tilt"` |
| Tune it | `data-radius="3"` | `data-spark-max="15"` |
| Restyle it | `--sh-primary` | `--spark-color`, which falls back to `--sh-tone` and then `--sh-primary` |

Spark reads Shine's tokens. `tone-danger` and `--sh-primary` recolor particles, borders, progress bars and cursors too.
Without Shine, Spark uses its own indigo default.

## Quick start

### Easiest: the auto-loader (one tag, loads only what the page uses)

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/shine@main/dist/shine.min.css">
<script src="https://cdn.jsdelivr.net/gh/asticore/spark@main/dist/spark.auto.min.js" defer></script>

<button class="btn spark-confetti">Party</button>          <!-- fetches features/confetti.min.js -->
<section class="spark-particles">…</section>               <!-- fetches features/particles.min.js + .css -->
<div class="spark-chart-funnel" data-spark-data="…"></div>   <!-- fetches the chart toolkit once + chart-funnel.min.js -->
```

The loader is 3.6 KB. It looks for `spark-*` classes and fetches only the matching files from the same folder it was loaded from, including each file's CSS. With `<html data-spark-observe>` it also loads files for elements added later. You can load a file by hand with `Spark.load('confetti')`, and `data-spark-base="…/dist/"` on the script tag points it at another folder.

### Pick files yourself (no loader)

```html
<script src="…/dist/spark.core.min.js" defer></script>
<link rel="stylesheet" href="…/dist/spark.core.min.css">
<script src="…/dist/features/confetti.min.js" defer></script>
<script src="…/dist/features/particles.min.js" defer></script>
<link rel="stylesheet" href="…/dist/features/particles.min.css">
```

Every effect has its own `dist/features/<name>.min.js`, plus a `.min.css` where it needs one. The order of the tags doesn't matter.

### Everything in one file

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/shine@main/dist/shine.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/spark@main/dist/spark.min.css">
<script src="https://cdn.jsdelivr.net/gh/asticore/spark@main/dist/spark.min.js" defer></script>
```

Charts and funnels are an optional add-on, so pages without charts never download them. Load order doesn't matter:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/spark@main/dist/spark-charts.min.css">
<script src="https://cdn.jsdelivr.net/gh/asticore/spark@main/dist/spark-charts.min.js" defer></script>
```

You don't need to call anything. Add classes:

```html
<section class="section spark-particles" data-spark-count="60" data-spark-links="true">
  <h1 class="spark-split" data-spark-by="letter">Hello</h1>
  <a class="btn btn-lg spark-magnetic spark-border-spin" href="#go">Get started</a>
</section>

<div class="spark-divider" data-spark-shape="waves" data-spark-animate="drift"></div>

<div class="spark-chart-funnel" data-spark-data="12400,7800,4100,1900" data-spark-labels="Visited|Signed up|Activated|Paid"></div>
<a class="btn spark-chart-spark" data-spark-background data-spark-data="3,5,4,7,9,12">Sales up 24%</a>

<div class="spark-stagger grid md:grid-cols-3 gap-4">
  <div class="card spark-reveal" data-spark-reveal="fade-up">One</div>
  <div class="card spark-reveal" data-spark-reveal="zoom">Two</div>
  <div class="card spark-tilt" data-spark-glare="true">Three</div>
</div>
```

### npm

```bash
npm i @asticore/spark shine-css
```

```js
import 'shine-css';
import '@asticore/spark/css';
import Spark from '@asticore/spark';          // effects bundle, starts itself
import '@asticore/spark/charts';              // + charts add-on (or '@asticore/spark/all' for both)
```

Or import only the features you use. Your bundler drops the rest:

```js
import { define, init } from '@asticore/spark/core';
import reveal from '@asticore/spark/features/reveal';
import particles from '@asticore/spark/features/particles';
import funnel from '@asticore/spark/charts/chart-funnel';

define(reveal, particles, funnel);
init();
```

## How it stays fast

- **Only features on the page start.** When the page loads, the core runs one `querySelectorAll` per feature. A missing feature costs nothing.
- **Heavy features are lazy.** Particles only start when they come near the viewport. Every animation loop pauses when it scrolls off-screen or the tab is hidden.
- **Shared observers.** All reveal, sticky and parallax elements share one `IntersectionObserver` and one passive, rAF-throttled scroll loop. Elements don't get their own.
- **Tiny core.** The core is about 2 KB gzip and most features add under 1 KB (sizes per feature are in the table below and in the docs). Custom builds can cut it further: `node build.js --only=reveal,tilt`.
- **Accessible defaults.**
  - Reduced-motion users see the static end state.
  - Pointer effects only run on mouse or trackpad.
  - Content stays visible without JS.
  - Dialogs and carousels support the keyboard and screen readers.

## Charts and funnels

Charts live in the add-on bundle and work the same way as effects: a class picks the chart and `data-spark-*` sets the data and options.

```html
<!-- inline data -->
<div class="spark-chart-bar" data-spark-data="[[42,58,51,77],[30,45,62,70]]"
     data-spark-names="2025|2026" data-spark-labels="Q1|Q2|Q3|Q4" data-spark-prefix="$"></div>

<!-- read a Shine table (first column = labels, other columns = series) -->
<div class="spark-chart-line" data-spark-source="#sales-table" data-spark-area></div>

<!-- any chart can decorate a button, card or section -->
<div class="card p-6 spark-chart-line" data-spark-background data-spark-data="4,6,5,9,12">…</div>
```

- **Types:** bar (grouped, stacked, horizontal), line and area, pie and donut, funnel, gauge and ring, radar, sparkline, scatter and bubble, heatmap and calendar, treemap, flow (Sankey), progress bars.
- **Funnel:**
  - Shapes: curved, straight, bars or pyramid, vertical or horizontal.
  - Shows step-to-step conversion and drop-off.
  - A compare mode puts two series side by side.
  - Legend keys hide stages.
- **Interaction:**
  - Tooltips on hover.
  - Arrow keys step through data points.
  - A click or Enter fires `spark:select` with `{ index, label, value, series }`.
  - Legend keys toggle series.
  - Charts redraw when resized and animate in when they scroll into view.
- **Live updates:** `el.dispatchEvent(new CustomEvent('spark:data', { detail: { labels, series } }))`.
- **Colours:** charts use Shine's tone tokens by default. Override them with `--spark-chart-1…7` or `data-spark-colors="#f43f5e|#8b5cf6"`.
- **Accessible:**
  - The SVG has `role="img"` and a title.
  - Every value is also in a list that screen readers can read.

### Giving charts data

Every chart reads `{ labels: [...], series: [{ name, data: [...], color? }] }`. You can supply it five ways:

1. **CSV attribute:** `data-spark-data="12,19,7|9,14,11"` with `data-spark-labels="Mon|Tue|Wed"` and `data-spark-names="Web|Mobile"`.
2. **JSON attribute:** `data-spark-data='{"labels":["Mon","Tue"],"series":[{"name":"Web","data":[12,19]}]}'`. Use single quotes around the attribute so the JSON can use double quotes.
3. **Inline JSON:** put a `<script type="application/json">{ … }</script>` inside the chart element.
4. **A Shine table:** `data-spark-source="#my-table"`. The first column holds the labels and the header row holds the series names.
5. **JavaScript:** `Spark.setData('#chart', { labels, series })`. Use this for API data and live updates.

Scatter, candlestick, timeline, flow and the heatmap calendar take their own row formats. Each one is shown in a blue *Data format* box in the docs.

## Extending

Built-in shapes, modes and easings are registered through the same plugin registry that you can use. Your own entries then work by name in `data-spark-*`:

```html
<script>
window.SparkConfig = { extend(E) {
  E.add('particle-shape', 'heart', (ctx, size) => { /* draw centred on 0,0 */ });
  E.add('format', 'gbp', v => '£' + Math.round(v).toLocaleString('en-GB'));
} };
</script>
<div class="spark-particles" data-spark-shape="heart|circle"></div>
<div class="spark-chart-bar" data-spark-format="gbp" data-spark-data="420,610,380"></div>
```

Plugin kinds:
- `particle-shape`
- `ambient-mode`
- `divider-shape`
- `confetti-shape`
- `trail-shape`
- `easing`
- `format`

You can also add whole chart types with `Spark.define` and the chart toolkit `Spark.charts`. Tooltips, keyboard navigation, legends and data updates come with it. You can add whole features with `Spark.define({ name, selector, defaults, init })` too. Reveal animations can be extended in CSS alone with `[data-spark-anim="name"]`.

## Customising

```html
<!-- behaviour: data-spark-* -->
<div class="spark-particles" data-spark-count="80" data-spark-interact="connect" data-spark-color="#f43f5e,#8b5cf6"></div>

<!-- look: --spark-* (or Shine tokens) -->
<button class="btn tone-accent spark-border-spin" style="--spark-border-speed:1.5s; --spark-border-width:3px">Loading…</button>
```

Global knobs: `--spark-duration`, `--spark-ease`, `--spark-distance`, `--spark-color`. Set them on `:root`, a section, or one element.

### Page switches

| Switch | Effect |
|---|---|
| `<html data-spark-manual>` | Don't auto-start. Call `Spark.init()` yourself. |
| `<html data-spark-observe>` | Start features on elements added later (SPAs, visual editors). |
| `<html data-spark-reduce>` | Force reduced motion. |
| `<html data-spark-margin="200px">` | How early lazy features start before they enter the viewport. |
| `data-spark-media="(min-width: 768px)"` | On any element: effects run only while the media query matches (e.g. desktop-only particles), starting/stopping as the viewport changes. |
| `window.SparkConfig = { auto: false, observe: true }` | The same switches from JS. Set it before the script loads. |

## Visual editors and SPAs

```js
Spark.observe();              // auto start/clean up nodes as the editor adds/removes blocks
Spark.refresh(block);         // re-read data-spark-* after a setting changed
Spark.destroy(block);         // remove listeners, timers and injected nodes
Spark.init(container);        // start features inside a container
Spark.define({ name, selector, defaults, init });   // add your own feature
```

Each feature maps onto a block setting. The class picks the effect and each `data-spark-*` attribute is one field in the settings panel. A builder can store the settings as attributes and call `Spark.refresh(el)` when one changes.

### React, Vue and Svelte

Each framework has a small helper that starts effects when a component mounts, refreshes them on update, and cleans up on unmount. Details are in [docs/integrations.md](docs/integrations.md).

```js
import { useSpark } from '@asticore/spark/react';   // useSpark(ref, [deps])
import { vSpark } from '@asticore/spark/vue';       // <div v-spark class="spark-tilt">
import { spark } from '@asticore/spark/svelte';     // <div use:spark class="spark-tilt">
```

## Build

```bash
npm install
npm run build                                   # dist/ + docs/index.html, fails over the gzip budget
node build.js --only=reveal,parallax,tilt       # custom build -> dist/custom/
node build.js --exclude=cursor,popup
npm test                                        # Playwright smoke test (chromium firefox webkit)
```

| File | What |
|---|---|
| `dist/spark.min.js` | Minified bundle: `window.Spark`, starts itself |
| `dist/spark-charts.min.js` / `spark-diagrams.min.js` | Charts add-on and diagrams add-on (tree, flow, sequence, cycle, fishbone); the auto-loader fetches each only when used |
| `dist/spark.esm.js` | ES module build |
| `dist/spark.min.css` | Styles, in `@layer spark` (ordered after Shine's layers) |
| `src/core.js`, `src/features/*.js` | ES sources for per-feature imports |
