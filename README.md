## Why Effix

[Shine](https://github.com/asticore/shine) does styling with **no JavaScript**: buttons, cards, modals, carousels, tooltips and colors.
Some effects can't be done in CSS alone. Canvas particles, pointer tracking, scroll math, timers and focus handling all need code.
**Effix is that code.** It works the same way Shine does:

| | Shine | Effix |
|---|---|---|
| Turn it on | `class="btn"` | `class="efx-tilt"` |
| Tune it | `data-radius="3"` | `data-efx-max="15"` |
| Restyle it | `--sh-primary` | `--efx-color`, which falls back to `--sh-tone` and then `--sh-primary` |

Effix reads Shine's tokens. `tone-danger` and `--sh-primary` recolor particles, borders, progress bars and cursors too.
Without Shine, Effix uses its own indigo default.

## Quick start

### Easiest: the auto-loader (one tag, loads only what the page uses)

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/shine@main/dist/shine.min.css">
<script src="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix.auto.min.js" defer></script>

<button class="btn efx-confetti">Party</button>          <!-- fetches features/confetti.min.js -->
<section class="efx-particles">…</section>               <!-- fetches features/particles.min.js + .css -->
<div class="efx-chart-funnel" data-efx-data="…"></div>   <!-- fetches the charts add-on once -->
```

The loader is 3.6 KB. It looks for `efx-*` classes and fetches only the matching files from the same folder it was loaded from, including each file's CSS. With `<html data-efx-observe>` it also loads files for elements added later. You can load a file by hand with `Effix.load('confetti')`, and `data-efx-base="…/dist/"` on the script tag points it at another folder.

### Pick files yourself (no loader)

```html
<script src="…/dist/effix.core.min.js" defer></script>
<link rel="stylesheet" href="…/dist/effix.core.min.css">
<script src="…/dist/features/confetti.min.js" defer></script>
<script src="…/dist/features/particles.min.js" defer></script>
<link rel="stylesheet" href="…/dist/features/particles.min.css">
```

Every effect has its own `dist/features/<name>.min.js`, plus a `.min.css` where it needs one. The order of the tags doesn't matter.

### Everything in one file

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/shine@main/dist/shine.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix.min.css">
<script src="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix.min.js" defer></script>
```

Charts and funnels are an optional add-on, so pages without charts never download them. Load order doesn't matter:

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix-charts.min.css">
<script src="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix-charts.min.js" defer></script>
```

You don't need to call anything. Add classes:

```html
<section class="section efx-particles" data-efx-count="60" data-efx-links="true">
  <h1 class="efx-split" data-efx-by="letter">Hello</h1>
  <a class="btn btn-lg efx-magnetic efx-border-spin" href="#go">Get started</a>
</section>

<div class="efx-divider" data-efx-shape="waves" data-efx-animate="drift"></div>

<div class="efx-chart-funnel" data-efx-data="12400,7800,4100,1900" data-efx-labels="Visited|Signed up|Activated|Paid"></div>
<a class="btn efx-chart-spark" data-efx-background data-efx-data="3,5,4,7,9,12">Sales up 24%</a>

<div class="efx-stagger grid md:grid-cols-3 gap-4">
  <div class="card efx-reveal" data-efx-reveal="fade-up">One</div>
  <div class="card efx-reveal" data-efx-reveal="zoom">Two</div>
  <div class="card efx-tilt" data-efx-glare="true">Three</div>
</div>
```

### npm

```bash
npm i effix shine-css
```

```js
import 'shine-css';
import 'effix/css';
import Effix from 'effix';          // effects bundle, starts itself
import 'effix/charts';              // + charts add-on (or 'effix/all' for both)
```

Or import only the features you use. Your bundler drops the rest:

```js
import { define, init } from 'effix/core';
import reveal from 'effix/features/reveal';
import particles from 'effix/features/particles';
import funnel from 'effix/charts/chart-funnel';

define(reveal, particles, funnel);
init();
```

## How it stays fast

- **Only features on the page start.** When the page loads, the core runs one `querySelectorAll` per feature. A missing feature costs nothing.
- **Heavy features are lazy.** Particles only start when they come near the viewport. Every animation loop pauses when it scrolls off-screen or the tab is hidden.
- **Shared observers.** All reveal, sticky and parallax elements share one `IntersectionObserver` and one passive, rAF-throttled scroll loop. Elements don't get their own.
- **Tiny core.** The core is about 2 KB gzip and most features add under 1 KB (sizes per feature are in the table below and in the docs). Custom builds can cut it further: `node build.js --only=reveal,tilt`.
- **Accessible defaults.**
  - Reduced-motion users see the static end state.
  - Pointer effects only run on mouse or trackpad.
  - Content stays visible without JS.
  - Dialogs and carousels support the keyboard and screen readers.

## Charts and funnels

Charts live in the add-on bundle and work the same way as effects: a class picks the chart and `data-efx-*` sets the data and options.

```html
<!-- inline data -->
<div class="efx-chart-bar" data-efx-data="[[42,58,51,77],[30,45,62,70]]"
     data-efx-names="2025|2026" data-efx-labels="Q1|Q2|Q3|Q4" data-efx-prefix="$"></div>

<!-- read a Shine table (first column = labels, other columns = series) -->
<div class="efx-chart-line" data-efx-source="#sales-table" data-efx-area></div>

<!-- any chart can decorate a button, card or section -->
<div class="card p-6 efx-chart-line" data-efx-background data-efx-data="4,6,5,9,12">…</div>
```

- **Types:** bar (grouped, stacked, horizontal), line and area, pie and donut, funnel, gauge and ring, radar, sparkline, scatter and bubble, heatmap and calendar, treemap, flow (Sankey), progress bars.
- **Funnel:**
  - Shapes: curved, straight, bars or pyramid, vertical or horizontal.
  - Shows step-to-step conversion and drop-off.
  - A compare mode puts two series side by side.
  - Legend keys hide stages.
- **Interaction:**
  - Tooltips on hover.
  - Arrow keys step through data points.
  - A click or Enter fires `efx:select` with `{ index, label, value, series }`.
  - Legend keys toggle series.
  - Charts redraw when resized and animate in when they scroll into view.
- **Live updates:** `el.dispatchEvent(new CustomEvent('efx:data', { detail: { labels, series } }))`.
- **Colours:** charts use Shine's tone tokens by default. Override them with `--efx-chart-1…7` or `data-efx-colors="#f43f5e|#8b5cf6"`.
- **Accessible:**
  - The SVG has `role="img"` and a title.
  - Every value is also in a list that screen readers can read.

### Giving charts data

Every chart reads `{ labels: [...], series: [{ name, data: [...], color? }] }`. You can supply it five ways:

1. **CSV attribute:** `data-efx-data="12,19,7|9,14,11"` with `data-efx-labels="Mon|Tue|Wed"` and `data-efx-names="Web|Mobile"`.
2. **JSON attribute:** `data-efx-data='{"labels":["Mon","Tue"],"series":[{"name":"Web","data":[12,19]}]}'`. Use single quotes around the attribute so the JSON can use double quotes.
3. **Inline JSON:** put a `<script type="application/json">{ … }</script>` inside the chart element.
4. **A Shine table:** `data-efx-source="#my-table"`. The first column holds the labels and the header row holds the series names.
5. **JavaScript:** `Effix.setData('#chart', { labels, series })`. Use this for API data and live updates.

Scatter, candlestick, timeline, flow and the heatmap calendar take their own row formats. Each one is shown in a blue *Data format* box in the docs.

## Extending

Built-in shapes, modes and easings are registered through the same plugin registry that you can use. Your own entries then work by name in `data-efx-*`:

```html
<script>
window.EffixConfig = { extend(E) {
  E.add('particle-shape', 'heart', (ctx, size) => { /* draw centred on 0,0 */ });
  E.add('format', 'gbp', v => '£' + Math.round(v).toLocaleString('en-GB'));
} };
</script>
<div class="efx-particles" data-efx-shape="heart|circle"></div>
<div class="efx-chart-bar" data-efx-format="gbp" data-efx-data="420,610,380"></div>
```

Plugin kinds:
- `particle-shape`
- `ambient-mode`
- `divider-shape`
- `confetti-shape`
- `trail-shape`
- `easing`
- `format`

You can also add whole chart types with `Effix.define` and the chart toolkit `Effix.charts`. Tooltips, keyboard navigation, legends and data updates come with it. You can add whole features with `Effix.define({ name, selector, defaults, init })` too. Reveal animations can be extended in CSS alone with `[data-efx-anim="name"]`.

## Customising

```html
<!-- behaviour: data-efx-* -->
<div class="efx-particles" data-efx-count="80" data-efx-interact="connect" data-efx-color="#f43f5e,#8b5cf6"></div>

<!-- look: --efx-* (or Shine tokens) -->
<button class="btn tone-accent efx-border-spin" style="--efx-border-speed:1.5s; --efx-border-width:3px">Loading…</button>
```

Global knobs: `--efx-duration`, `--efx-ease`, `--efx-distance`, `--efx-color`. Set them on `:root`, a section, or one element.

### Page switches

| Switch | Effect |
|---|---|
| `<html data-efx-manual>` | Don't auto-start. Call `Effix.init()` yourself. |
| `<html data-efx-observe>` | Start features on elements added later (SPAs, visual editors). |
| `<html data-efx-reduce>` | Force reduced motion. |
| `<html data-efx-margin="200px">` | How early lazy features start before they enter the viewport. |
| `data-efx-media="(min-width: 768px)"` | On any element: effects run only while the media query matches (e.g. desktop-only particles), starting/stopping as the viewport changes. |
| `window.EffixConfig = { auto: false, observe: true }` | The same switches from JS. Set it before the script loads. |

## Visual editors and SPAs

```js
Effix.observe();              // auto start/clean up nodes as the editor adds/removes blocks
Effix.refresh(block);         // re-read data-efx-* after a setting changed
Effix.destroy(block);         // remove listeners, timers and injected nodes
Effix.init(container);        // start features inside a container
Effix.define({ name, selector, defaults, init });   // add your own feature
```

Each feature maps onto a block setting. The class picks the effect and each `data-efx-*` attribute is one field in the settings panel. A builder can store the settings as attributes and call `Effix.refresh(el)` when one changes.

### React, Vue and Svelte

Each framework has a small helper that starts effects when a component mounts, refreshes them on update, and cleans up on unmount. Details are in [docs/integrations.md](docs/integrations.md).

```js
import { useEffix } from 'effix/react';   // useEffix(ref, [deps])
import { vEffix } from 'effix/vue';       // <div v-effix class="efx-tilt">
import { effix } from 'effix/svelte';     // <div use:effix class="efx-tilt">
```

## Build

```bash
npm install
npm run build                                   # dist/ + docs/index.html, fails over the gzip budget
node build.js --only=reveal,parallax,tilt       # custom build -> dist/custom/
node build.js --exclude=cursor,popup
npm test                                        # Playwright smoke test (chromium firefox webkit)
```

| File | What |
|---|---|
| `dist/effix.min.js` | Minified bundle: `window.Effix`, starts itself |
| `dist/effix-charts.min.js` / `effix-diagrams.min.js` | Charts add-on and diagrams add-on (tree, flow, sequence, cycle, fishbone); the auto-loader fetches each only when used |
| `dist/effix.esm.js` | ES module build |
| `dist/effix.min.css` | Styles, in `@layer effix` (ordered after Shine's layers) |
| `src/core.js`, `src/features/*.js` | ES sources for per-feature imports |
