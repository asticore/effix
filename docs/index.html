Effix JavaScript effects

Effects that need JavaScript — particles — applied with classes, tuned with data-efx-*.

Built as the partner of Shine CSS: Shine handles styling with zero JS, Effix adds behaviour and reads Shine's tokens, so tone-* classes and --sh-primary recolour every effect. Only the features found on the page start; heavy ones wait until they scroll into view.

Get started Browse 70 features

Drop it in your <head>

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/shine@main/dist/shine.min.css">
<script src="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix.auto.min.js" defer></script>

Quick start

Four ways in

1 · Auto-loader easiest

One tag. It looks for efx-* classes and fetches only those features' files (and the charts add-on only if a chart is on the page). Add class="efx-confetti" to a button and the confetti file loads by itself. With <html data-efx-observe> it also loads files for elements added later.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/shine@main/dist/shine.min.css">
<script src="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix.auto.min.js" defer></script>

2 · Pick files yourself

The core plus one tag per feature, from dist/features/. Tag order doesn't matter.

<script src="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix.core.min.js" defer></script>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix.core.min.css">
<!-- then one tag per feature you use -->
<script src="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/features/confetti.min.js" defer></script>
<script src="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/features/particles.min.js" defer></script>
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/features/particles.min.css">

3 · Everything bundled

All effects in one file, plus the optional charts add-on. Best when a site uses many features on every page.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/shine@main/dist/shine.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix.min.css">
<script src="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix.min.js" defer></script>

<!-- optional: charts & funnels add-on -->

<script src="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix-charts.min.js" defer></script>

How it works

Class turns it on, attributes tune it, variables style it

Every feature follows one pattern, so learning one teaches all.

<button class="btn tone-accent efx-border-spin efx-magnetic"
        data-efx-strength="0.4"
        style="--efx-border-speed:2s">
  Subscribe
</button>
  1. efx-* class — picks the feature. Combine as many as you like on one element.
  2. data-efx-* attributes — behaviour options (counts, speeds, triggers). Each feature lists its options below.
  3. --efx-* CSS variables — visual knobs. Colors fall back to Shine: --efx-color → --sh-tone → --sh-primary.
  4. Speed — on load the core asks the page once per feature (querySelectorAll); missing features cost nothing. Canvas features are lazy and every loop pauses off-screen and in hidden tabs.
  5. Accessible by default — reduced-motion users get the static end state, pointer effects only run with a mouse, content is visible without JS.

Visual editors & SPAs

Works when the page keeps changing

Page builders re-render blocks constantly. Turn on observe and Effix starts new blocks and cleans up removed ones. When the editor changes an option, call Effix.refresh(el).

<html data-efx-observe>
…
// editor changed a block's settings
block.dataset.efxCount = 80;
Effix.refresh(block);

// editor canvas: keep things still while editing
document.documentElement.toggleAttribute('data-efx-reduce', editing);

Data input

Five ways to give a chart its data

Every chart reads the same data shape. Pick whichever way suits your page; when several are present the order of precedence is: JavaScript update → table → data-efx-data → inline JSON.

The shape

{
  "labels": ["Mon", "Tue", "Wed"],          // x categories / slices / stages
  "series": [
    { "name": "Web",    "data": [12, 19, 7] },
    { "name": "Mobile", "data": [9, 14, 11], "color": "#db2777" }   // color optional
  ]
}

Shorthands also work: a flat list [12, 19, 7], a list of series [[3,5,2],[4,1,6]], or label/value pairs [{"label":"Mon","value":12}]. Charts with special data (scatter, candlestick, timeline, flow, heatmap calendar) show their own format in a blue Data format box below.

1 · Attribute, comma list

Quickest. Separate series with |, name them with data-efx-names.

<div class="efx-chart-bar"
     data-efx-data="12,19,7|9,14,11"
     data-efx-labels="Mon|Tue|Wed"
     data-efx-names="Web|Mobile"></div>

2 · Attribute, JSON

Any shape above. Wrap the attribute in single quotes so the JSON can use double quotes.

<div class="efx-chart-line"
     data-efx-data='{"labels":["Mon","Tue","Wed"],
                     "series":[{"name":"Web","data":[12,19,7]}]}'></div>

3 · Inline JSON script

Best for bigger data or server-rendered pages: put a JSON script inside the chart element.

<div class="efx-chart-pie">
  <script type="application/json">
    { "labels": ["Organic", "Direct", "Social"],
      "series": [{ "name": "Visits", "data": [4200, 2800, 900] }] }
  </script>
</div>

4 · A Shine table

Keep one accessible table and chart it. First column = labels, header row = series names.

<table class="table" id="sales">
  <thead><tr><th>Month</th><th>2025</th><th>2026</th></tr></thead>
  <tbody><tr><td>Jan</td><td>42</td><td>51</td></tr> …</tbody>
</table>
<div class="efx-chart-bar" data-efx-source="#sales"></div>

5 · JavaScript

Load or update data at any time (API calls, live dashboards). Same shape as above.

// any time after Effix has loaded
Effix.setData('#sales-chart', {
  labels: ['Jan', 'Feb', 'Mar'],
  series: [{ name: 'Revenue', data: [42, 58, 51] }],
});

// e.g. from your API
fetch('/api/sales').then(r => r.json())
  .then(data => Effix.setData('#sales-chart', data));

Live: update from JavaScript

Extend Effix

Add your own shapes, modes, formats, charts and features

Built-in variants are registered through the same plugin registry you use, so yours are first-class: register once, then use the name in data-efx-* like any built-in.

Register before Effix starts with window.EffixConfig.extend (put it in a normal <script> above the Effix tags), or any time later with Effix.add(…) followed by Effix.refresh(el). This page runs exactly the code on the right:

window.EffixConfig = {
  extend(E) {
    // 1. A particle shape: draw centred on 0,0 at the given size (fill colour is already set).
    E.add('particle-shape', 'heart', (ctx, size) => {
      const s = size / 2;
      ctx.beginPath();
      ctx.moveTo(0, s * 0.6);
      ctx.bezierCurveTo(-s * 1.4, -s * 0.4, -s * 0.5, -s * 1.3, 0, -s * 0.5);
      ctx.bezierCurveTo(s * 0.5, -s * 1.3, s * 1.4, -s * 0.4, 0, s * 0.6);
      ctx.fill();
    });

    // 2. A number format any chart can use with data-efx-format="gbp".
    E.add('format', 'gbp', v => '£' + Math.round(v).toLocaleString('en-GB'));
  },
};

// 3. A whole new chart type built on the chart toolkit (Effix.charts),
//    and 4. a tiny custom feature. Both work like built-ins: class + data-efx-*.
document.addEventListener('efx:ready', ({ detail: E }) => {
  const { chart, COMMON, nice, linear, axes, s } = E.charts;

  E.define({
    name: 'chart-dots',
    selector: '.efx-chart-dots',
    lazy: true,
    defaults: { ...COMMON, radius: 6 },
    init: (el, o) => chart(el, o, ({ g, w, h, data, visible, colors, fmt }) => {
      const pad = { t: 10, r: 10, b: 28, l: 48 };
      const sc = nice(0, Math.max(1, ...visible.flatMap(sr => sr.values)));
      const y = linear([sc.min, sc.max], [h - pad.b, pad.t]);
      const x = i => pad.l + (i + 0.5) * (w - pad.l - pad.r) / data.labels.length;
      axes(g, { w, h, pad, y, ticks: sc.ticks, labels: data.labels, x, fmt });
      const marks = [];
      visible.forEach(sr => sr.values.forEach((v, i) => {
        s('line', { x1: x(i), x2: x(i), y1: y(0), y2: y(v), stroke: colors[sr.index], 'stroke-width': 2 }, g);
        const node = s('circle', { cx: x(i), cy: y(v), r: o.radius, fill: colors[sr.index], class: 'efx-chart__mark' }, g);
        marks.push({ x: x(i), y: y(v), label: data.labels[i], value: v, series: sr.name, node, index: i });
      }));
      return marks; // tooltips, keyboard, legend and efx:select come free
    }),
  });

  E.define({
    name: 'blink',
    selector: '.my-blink',
    defaults: { speed: 600 },                  // read from data-efx-speed
    init(el, o) {
      const t = setInterval(() => el.classList.toggle('is-on'), o.speed);
      return () => { clearInterval(t); el.classList.remove('is-on'); }; // cleanup
    },
  });
});
