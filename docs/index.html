Effix JavaScript effects

Effects that need JavaScript — particles — applied with classes, tuned with data-efx-*.

Built as the partner of Shine CSS: Shine handles styling with zero JS, Effix adds behaviour and reads Shine's tokens, so tone-* classes and --sh-primary recolour every effect. Only the features found on the page start; heavy ones wait until they scroll into view.

Get started Browse 53 features

Drop it in your <head>

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/shine@main/dist/shine.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix.min.css">

Quick start

Three ways in

1 · CDN

Shine for styling, Effix for behaviour. The script is deferred and starts itself.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/shine@main/dist/shine.min.css">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix.min.css">
<script src="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix.min.js" defer></script>

<!-- optional: charts & funnels add-on -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix-charts.min.css">
<script src="https://cdn.jsdelivr.net/gh/asticore/effix@main/dist/effix-charts.min.js" defer></script>

2 · npm

Full bundle; auto-starts on import.

npm i effix shine-css

import 'shine-css';
import 'effix/css';
import Effix from 'effix';

3 · Pick features

Import only what you use from the ES sources — bundlers drop the rest.

import { define, init } from 'effix/core';
import reveal from 'effix/features/reveal';
import tilt from 'effix/features/tilt';

define(reveal, tilt);
init();

How it works

Class turns it on, attributes tune it, variables style it

Every feature follows one pattern, so learning one teaches all.

<button class="btn tone-accent efx-border-spin efx-magnetic"
        data-efx-strength="0.4"
        style="--efx-border-speed:2s">
  Subscribe
</button>
  1. efx-* class — picks the feature. Combine as many as you like on one element.
  2. data-efx-* attributes — behaviour options (counts, speeds, triggers). Each feature lists its options below.
  3. --efx-* CSS variables — visual knobs. Colors fall back to Shine: --efx-color → --sh-tone → --sh-primary.
  4. Speed — on load the core asks the page once per feature (querySelectorAll); missing features cost nothing. Canvas features are lazy and every loop pauses off-screen and in hidden tabs.
  5. Accessible by default — reduced-motion users get the static end state, pointer effects only run with a mouse, content is visible without JS.

Page-level switches

SwitchEffect
<html data-efx-manual>Do not auto-start. Call Effix.init() yourself.
<html data-efx-observe>Auto-start features on elements added later (SPAs, visual editors, infinite lists).
<html data-efx-reduce>Force reduced motion (static end states), e.g. for an editor canvas or a user toggle.
<html data-efx-margin="200px">How early lazy features (particles…) start before entering the viewport.
data-efx-skipOn any element: observe() ignores nodes inside it.
window.EffixConfig = { auto:false, observe:true }Same switches from JS, set before the script loads.

Visual editors & SPAs

Works when the page keeps changing

Page builders re-render blocks constantly. Turn on observe and Effix starts new blocks and cleans up removed ones. When the editor changes an option, call Effix.refresh(el).

<html data-efx-observe>
…
// editor changed a block's settings
block.dataset.efxCount = 80;
Effix.refresh(block);

// editor canvas: keep things still while editing
document.documentElement.toggleAttribute('data-efx-reduce', editing);
MethodWhat it does
Effix.init(root?)Scan root (default document) and start every feature found. Safe to call again — already-running elements are skipped.
Effix.destroy(root?, name?)Stop features on root and its children, removing listeners, timers and injected nodes.
Effix.refresh(el, name?)destroy + init: re-reads data-efx-* after you change them.
Effix.observe(target?)Watch the DOM: new nodes start automatically, removed nodes are cleaned up. Same as <html data-efx-observe>.
Effix.disconnect()Stop watching the DOM.
Effix.define(feature)Register your own feature ({ name, selector, defaults, init }).
Effix.features()Names of the features in this build.
Effix.isMounted(el, name)Whether a feature is running on el.
